Data JSON Converter

Paste raw Omnisend data → get clean JSON ready for data.json · Campaigns & Monthly

How to use
Copy your campaign data from Omnisend and paste it below. Each campaign block should follow this column order.
1
In Omnisend, open your Campaigns report and select all rows for the campaigns you want to add.
2
Copy (Ctrl+C) and paste into the text area below. Tab-separated or line-by-line both work.
3
Set the Starting ID to continue from your last campaign (e.g. if you have 14, set it to 15).
4
Click Convert — review the output, then Copy JSON and paste the new campaign objects into your data.json campaigns array.
Expected column order per campaign block
Row 1Campaign Name
Row 2Segment / Audience
Row 3Channel (Email / SMS)
Row 4"Sent" (status label)
Row 5Date & time (e.g. Mar 21, 2026 at 8:00 AM)
Row 6Recipients sent (number)
Row 7Open rate % (or N/A for SMS)
Row 8Open count (number)
Row 9Click rate %
Row 10Click count (number)
Row 11Revenue ($)
Row 12Orders (number)
📅 Date format: Output will be in the format "Mar 19, 2026 at 10:00 AM" to match your existing data.json

How to use — Monthly
Paste your full Omnisend monthly summary block below. The converter extracts data from the Email subscribers section only (not SMS/Push).
1
In Omnisend, open the monthly overview for the month you want to add and copy all the text.
2
Paste into the text area below — the converter reads the raw block and fills all fields automatically.
3
Check the parsed fields, correct anything if needed, then set the Month label (e.g. Mar 2026).
4
Click Convert → copy the output and add it to the monthly.historicalData array in your data.json.
📊 Calculation Formulas
Unsubscribe Rate = (Email Unsubscribes ÷ Total Email Subscribers) × 100
Net Growth = New Email Subscribers − Email Unsubscribes
Engaged List = ✏️ Manually editable — based on your own segment definition
💡 Note: Only email subscriber data is used for unsubscribe rate calculations.
📝 Output format: Monthly entries will be a single line (not pretty-printed) to match your data.json style.
